# Telegram Support Bot

## Пользователь может сделать:

1. Отправить текстовый вопрос - бот создаст или продолжит открытый запрос и попробует ответить через AI.
2. Отправить фото, стикер, видео, аудио, голосовое или документ - бот передаст сообщение оператору и не будет отвечать через AI.
3. Продолжить диалог после ответа оператора - сообщение сохранится в этом же запросе и будет передано оператору, AI больше не будет вмешиваться в запрос.
4. Получить ответ от оператора - бот отправит сообщение оператора пользователю от своего имени, включая текст, фото, видео, аудио, голосовые и документы.
5. Начать новый запрос после закрытия старого - следующее сообщение создаст новый запрос.

## Оператор может сделать:

1. Открыть список запросов - бот покажет открытые запросы с номером, Telegram user id пользователя и статусом.
2. Листать список запросов - бот покажет предыдущую или следующую страницу списка.
3. Открыть запрос - бот покажет последнюю страницу истории запроса.
4. Листать историю запроса - бот покажет предыдущий или следующий вопрос пользователя и ответы на него.
5. Посмотреть вложения - бот отправит оригинальные медиа-сообщения с текущей страницы истории.
6. Ответить на запрос текстом - бот отправит текст пользователю от своего имени и сохранит ответ в истории.
7. Ответить на запрос медиа-сообщением - бот отправит пользователю копию фото, видео, аудио, голосового, документа или другого поддерживаемого сообщения.
8. Отменить ввод ответа - бот вернет оператора к просмотру запроса без отправки сообщения пользователю.
9. Закрыть запрос - бот переведет запрос в закрытый статус, и пользователь сможет начать новый запрос.
10. Получить уведомление о новом сообщении - бот сообщит оператору, когда пользователь написал в запрос, который уже находится в ручном режиме.

## Администратор может сделать:

1. Открыть админ-меню командой `/admin` - бот покажет меню администратора.
2. Открыть список запросов - бот покажет открытые запросы так же, как оператору.
3. Добавить support - бот выдаст указанному Telegram user id права оператора поддержки.
4. Удалить support - бот снимет права оператора поддержки с указанного Telegram user id.
5. Отменить админ-действие - бот сбросит текущий ввод и вернет админ-меню.
6. Выполнять действия оператора - администратор может смотреть запросы, листать историю, смотреть вложения, отвечать пользователям и закрывать запросы.
